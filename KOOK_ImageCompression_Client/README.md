# KOOK Image Compression Client

一个简单的图片压缩客户端工具，支持拖拽上传、压缩和自动复制到剪贴板功能。

## 功能特点

- ✅ 支持拖拽上传图片
- ✅ 支持点击按钮选择图片
- ✅ 高质量图片压缩
- ✅ 实时显示压缩后的图片
- ✅ 自动复制到剪贴板，可直接粘贴使用
- ✅ 显示压缩前后的大小和压缩率

## 安装说明

### 1. 安装Python

确保您的系统已安装Python 3.x版本。您可以从[Python官网](https://www.python.org/downloads/)下载并安装。

### 2. 安装依赖项

打开命令提示符，进入客户端目录，运行以下命令：

```bash
# 安装所需依赖
python -m pip install -r requirements.txt
```

### 3. 启动客户端

#### 方法一：使用批处理文件

直接双击运行 `启动客户端.bat` 文件。

#### 方法二：命令行启动

```bash
# 进入客户端目录
cd KOOK_ImageCompression_Client

# 启动客户端
python client.py
```

## 使用方法

### 1. 上传图片

**方法一：拖拽上传**
- 从文件资源管理器中直接拖拽图片到左侧的上传区域
- 程序会自动识别图片文件并加载

**方法二：按钮选择**
- 点击下方"选择图片"按钮
- 从文件浏览器中选择要压缩的图片

### 2. 执行压缩

- 点击"压缩图片"按钮
- 压缩过程会自动进行

### 3. 使用压缩结果

- **查看预览**：右侧会显示压缩后的图片
- **直接粘贴**：压缩后的图片会自动复制到剪贴板，您可以直接在其他应用中粘贴使用（例如：Ctrl+V）
- **查看信息**：右侧会显示压缩前后的文件大小和压缩率

## 支持的图片格式

- JPEG (.jpg, .jpeg)
- PNG (.png)
- BMP (.bmp)
- GIF (.gif)

## 技术说明

- **压缩质量**：固定为90，这是一个平衡质量和文件大小的最佳设置
- **压缩格式**：使用JPEG格式进行压缩
- **自动处理**：自动将RGBA格式的图片转换为RGB格式
- **复制功能**：使用Windows剪贴板API实现自动复制

## 常见问题

### 1. 拖拽上传失败
- 请确保拖拽的是图片文件
- 请确保图片文件格式受支持

### 2. 客户端启动失败
- 请检查是否安装了所有依赖项
- 请确保Python环境正常
- 可尝试重新安装依赖：`python -m pip install -r requirements.txt`

### 3. 压缩后图片质量不佳
- 压缩质量已固定为90，这是一个平衡质量和大小的最佳值
- 对于特别重要的图片，建议使用原始格式
